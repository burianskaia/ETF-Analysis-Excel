# ETF Analysis — Excel

## Overview

This project was completed as a **group assignment for the Asset Management course**. It focuses on the financial analysis of the Vanguard Information Technology ETF (VGT), applying quantitative calculations and financial analysis techniques to evaluate an exchange-traded fund.

The project combines an Excel-based analytical model with a written report, connecting quantitative analysis with the interpretation of investment-related results.

**My contribution:** Although the project was completed as part of a group, I was responsible for **all calculations** in the analytical workbook. This involved implementing the quantitative component of the project in Excel and providing the calculations underlying the analysis.

## Project Files

### `VGT Analysis.xlsx`
The Excel workbook containing the calculations performed for the ETF analysis. It represents the quantitative component of the project and provides the basis for the financial analysis.

### `ETF Analysis Report.pdf`
The accompanying report presenting the project and its analysis in a written format.

## Tools

- Microsoft Excel
- Financial and quantitative analysis techniques

This project was developed as part of university coursework in Asset Management. It demonstrates practical experience with Excel-based financial analysis and the application of quantitative methods to an investment-related case study.
